# 🌍 AI4EO-Learning

A complete learning repository for Artificial Intelligence in Earth Observation.

This repository documents my learning journey through the NPTEL/SWAYAM course **AI for Earth Observation**, along with practical implementations, notes, research papers, datasets, and mini-projects.

## Repository Goals

- Learn Remote Sensing
- Learn GIS
- Learn Satellite Image Processing
- Implement every important algorithm
- Build Earth Observation projects
- Read research papers
- Maintain structured notes
- Create reusable code examples

## Tech Stack

- Python

- OpenCV

- GeoPandas
- GDAL
- Matplotlib
- Scikit-Learn
- PyTorch
- Google Earth Engine
